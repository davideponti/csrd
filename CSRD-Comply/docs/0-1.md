## FASE 1 — PARSE & MAPPA ESRS (Steps 5-7)

### Step 5: Ingegnerizzazione Tassonomia ESRS

**File:** `ai-engine/esrs_parser/ingest_taxonomy.py`

**Funzionalità:**
- Legge file Excel EFRAG IG 3 "List of ESRS datapoints.xlsx"
- Mappa colonne: Standard (col A), DR ref (B), Paragraph (C), Description (D), Datapoint name (F), Data type (G), Voluntary flag (I), Phase-in (K), SFDR ref (L)
- Mapping data types: monetary/emission/energy/volume/count → `numerical`, boolean → `boolean`, narrative/text → `narrative`
- Parsing phase-in year da testo (es. "phase-in 2026" → 2026)
- Popola tabella `esrs_datapoints` con ~1.100 records (previsti)
- **Seed:** 25 topic ESRS in `sustainability_matters` (E1-E5 environmental, S1-S4 social, G1 governance)

**Tipi topic seedati:**
- **Environmental (13):** Climate change (E1), Pollution (E2), Water (E3), Biodiversity (E4), Circular economy (E5)
- **Social (8):** Own workforce (S1), Value chain workers (S2), Communities (S3), Consumers (S4)
- **Governance (4):** Business conduct (G1)

---

### Step 6: NLP Parser — ESRS ↔ Azienda

**File:** `ai-engine/esrs_parser/esrs_nlp_mapper.py`

**Classe `ESmapper`:**
- Supporta provider **OpenAI** (GPT-4o con `response_format=json_object`) e **Anthropic** (Claude 3.5 Sonnet)
- **Input:** testo Disclosure Requirement + profilo azienda (settore NACE, attività, paesi, dipendenti)
- **Output JSON:** `{ applicable, confidence, data_source_suggestion, difficulty (1-5), priority (high/medium/low), rationale }`
- **Fallback rule-based:** quando LLM non disponibile, usa euristiche per settore:
  - Ufficio (NACE M-N, J): emissioni rilevanti ma biodiversity no
  - Manufacturing (C-F): alta rilevanza per emissioni/rifiuti/energia
  - PMI <50 dip.: esclude scope 3 cat.15 (investments)
- System prompt specializzato in CSRD compliance

---

### Step 7: Gap Analysis Automatica

**File:** `ai-engine/esrs_parser/gap_analyzer.py`

**Classe `GapAnalyzer`:**
- **Input:** company_id
- **Logica:** per ogni datapoint obbligatorio:
  1. Cerca in `emissions_data` se topic emissioni/ GHG
  2. Cerca in `materiality_scores` se topic impatto/IRO
  3. Classifica come `COMPLETE`, `PARTIAL` o `MISSING`
  4. Raggruppa per standard ESRS (E1, E2, S1, G1...)
  5. Genera azioni prioritarie con suggerimenti

**Output API (dict):**
```json
{
  "total_required": 320,
  "complete": 45,
  "partial": 120,
  "missing": 155,
  "completion_percentage": 14,
  "gaps_by_standard": {
    "ESRS E1": { "required": 80, "complete": 20, "partial": 40, "missing": 20 }
  },
  "priority_actions": [
    { "datapoint": "Gross Scope 1 GHG", "priority": "critical", "effort": "medium", "suggestion": "..." }
  ]
}
```

### Step 8: Valutazione di Contesto Aziendale (Context Questionnaire)

**File:** `backend/app/services/context_questionnaire.py`

**Funzionalità:**
- Questionario dinamico AI-adattivo in 3 fasi:
  1. **Universale**: settore, dimensioni, fatturato, dipendenti, paesi operativi
  2. **Settoriale**: domande specifiche per NACE (C=manifatturiero, J=IT, M=servizi, H=logistica, F=costruzioni, A=agricoltura, G=commercio)
  3. **Value Chain**: mappatura upstream/downstream, stakeholder
- Ogni domanda è associata a topic ESRS pertinenti (E1, E2, S1, G1, etc.)
- Metodo `save_context()`: popola tabella `company_context` con tutti i campi
- Metodo `get_all_questions()`: restituisce domande per fase e settore

---

### Step 9: Identificazione IRO (Impacts, Risks, Opportunities)

**File:** `ai-engine/materiality_engine/iro_generator.py`

**Funzionalità:**
- **Database IRO predefinito**: ~120 IRO template organizzati per settore NACE
- **Categorie**: impact (21), risk (40+), opportunity (20+) per topic ESRS (E1-E5, S1-S4, G1)
- **Severità**: high/medium/low calcolata su default scoring
- **Metodo `generate_iros_for_company()`**:
  1. Filtra IRO per settore aziendale
  2. Aggiunge IRO generici universali (base climate change, governance)
  3. Applica esclusioni per settori non applicabili
  4. Assegna scoring predefinito (scale, magnitude) per settore
- Output: lista IRO con type, topic, name, description, default scores

---

### Step 10: Scoring Engine (Doppia Materialità)

**File:** `ai-engine/materiality_engine/scoring_engine.py`

**Funzionalità:**
- **Impact Score Formula**: (Scale × 0.3) + (Scope × 0.3) + (Irremediability × 0.2) + (Likelihood × 0.2)
- **Financial Score Formula**: (Magnitude × 0.6) + (Likelihood × 0.4)
- **Double Materiality Score**: max(Impact, Financial)
- **Threshold**: ≥ 3.0/5.0 = `is_material`
- **Quadranti**: double_material, impact_material, financial_material, non_material
- **Metodi**:
  - `score_single_datapoint()` — calcola e aggiorna singolo score
  - `calculate_assessment_scores()` — calcola tutti gli score di un assessment
  - `get_materiality_matrix()` — dati per scatter plot (Impact vs Financial)
- Pesi configurabili secondo EFRAG IG 1 Materiality Assessment

---

### Step 11: Report di Doppia Materialità

**File:** `ai-engine/materiality_engine/materiality_report.py`

**Funzionalità:**
- **ESRS 2 IRO-1**: Description of the process to identify and assess material IROs
  - Include metodologia, contesto aziendale, value chain, stakeholder
  - Lista topic materiali con conteggio
- **ESRS 2 IRO-2**: Disclosure Requirements covered by the undertaking
  - Raggruppa datapoint materiali per standard ESRS
  - Mostra impact_score e financial_score per ogni datapoint
- **Full Report**: report completo con executive summary, sezioni IRO-1/2
- **Narrative Generator**: trasforma dati numerici in descrizione conforme ESRS

## FASE 3 — CARBON FOOTPRINT CALCULATOR (Steps 12-16)

---

### Step 12: GHG Protocol Scope 1 Calculator

**File:** `ai-engine/carbon_calculator/scope1.py`

**Funzionalità:**
- **Categorie**:
  1. Stationary combustion (natural gas, diesel heating, LPG, biomass)
  2. Mobile combustion (diesel/petrol/electric vehicles)
  3. Fugitive emissions (refrigerants R410A, R134a, R32, R290)
- **Emission Factors**: DEFRA UK 2025, EPA US 2025, IPCC AR6 2025
  - Natural gas: 0.184 kgCO2e/kWh
  - Diesel vehicle: 0.170 kgCO2e/km
  - R410A: 2088 kgCO2e/kg (GWP)
- **Country-specific grid factors**: IT, DE, FR, ES, UK, NL, BE, AT, + EU_avg
- Metodo: Activity_Data × Emission_Factor
- Output: tCO2eq totali con breakdown per categoria

---

### Step 13: GHG Protocol Scope 2 Calculator

**File:** `ai-engine/carbon_calculator/scope2.py`

**Funzionalità:**
- **Dual reporting** (richiesto da ESRS E1-6):
  1. **Location-based**: fattore medio rete nazionale (AIE/Eurostat 2025)
  2. **Market-based**: fattore AIB Residual Mix 2025
- **28 paesi EU** con fattori specifici (es. IT: 0.286, FR: 0.055, DE: 0.374)
- **Green tariff**: se contratto energia verde certificata (GO), fattore = 0
- Differenza location vs market calcolata automaticamente
- Supporto steam/heating/cooling acquistato

---

### Step 14: GHG Protocol Scope 3 Calculator (15 Categorie)

**File:** `ai-engine/carbon_calculator/scope3.py`

**Funzionalità:**
- **Metodo spend-based** (adatto per PMI): €speso × emission_factor per settore NACE
- **40+ codici NACE** con fattori specifici (EXIOBASE 3 + Ecoinvent 3.10)
  - Esempi: C10 Food: 0.45, C20 Chemicals: 0.89, J62 IT: 0.07, M69 Legal: 0.05
- **Categorie implementate**:
  - Cat.1: Purchased goods (spend-based)
  - Cat.4: Upstream transportation (tkm)
  - Cat.5: Waste (per tipo rifiuto)
  - Cat.6: Business travel (per mezzo)
  - Cat.7: Employee commuting
  - + Categorie 2, 3
- **Travel factors**: flight (short/medium/long), train, bus, car
- **Waste factors**: mixed, paper, plastic, glass, metal, organic, hazardous
- Output: upstream + downstream totals

---

### Step 15: Data Collection Automation System

**File:** `ai-engine/carbon_calculator/data_collector.py`

**Funzionalità:**
- **PDF OCR Parser**:
  - Estrae da testo bolletta: provider, consumo kWh, periodo, costo
  - Riconosce formato elettrico e gas
  - Confidence scoring per ogni campo estratto
- **Accounting Integration**:
  - Processa transazioni XERO/QuickBooks
  - Mappa categorie contabili a codici NACE
  - Calcolo spend-based aggregato
- **HR Data**: employee count, full-time/part-time, remote workers, commuting
- **Fleet Data**: per tipo veicolo, km annui

---

### Step 16: AI Validation Engine per Dati Emissioni

**File:** `ai-engine/carbon_calculator/validation_engine.py`

**Funzionalità:**
- **Range check**: verifica se i dati sono nel range atteso per PMI
  - Scope 1 per dipendente: 10-20,000 kgCO2e
  - Scope 2 per dipendente: 50-15,000 kgCO2e
- **Sector benchmark**: confronta con 8 settori (C, M, H, A, F, G, J, DEFAULT)
  - Alert se > 3× il benchmark di settore
- **Year-over-year**: alert se variazione > 50%
- **Missing data detection**: per settore (es. logistica senza fleet = alert)
- **Unit consistency**: rileva possibili errori kg vs t, kWh vs MWh
- **Validation Score**: 0-100 con penalty per severità
- **Output**: score, alert per severità, raccomandazioni
