# Step 8-9: Context Questionnaire + IRO Generator with AI

## Cosa è stato implementato

Sono stati implementati due componenti fondamentali per il processo di **Doppia Materialità**:
- **Step 8**: Questionario di Contesto Aziendale (Context Questionnaire)
- **Step 9**: Generatore IRO (Impacts, Risks, Opportunities) con supporto AI

---

## Step 8 - Context Questionnaire

### File creato: `backend/app/services/context_questionnaire.py`

Servizio back-end che fornisce un questionario strutturato in **3 fasi progressive** per raccogliere il contesto aziendale:

| Fase | Tipo | Descrizione |
|------|------|-------------|
| **Fase 1** | Universale | Domande base: settore, dipendenti, fatturato, paesi operativi, attività core |
| **Fase 2** | Settoriale | Domande specifiche per codice NACE (es. C=Manifatturiero: consumi energetici, sostanze chimiche, rifiuti; M=Servizi: mobility, fornitori IT; A=Agricoltura: pesticidi, biodiversità; ecc.) |
| **Fase 3** | Value Chain | Catena del valore (upstream/downstream), stakeholder, geografia, certificazioni |

### Endpoint API implementati

- **`GET /assessment/{id}/questionnaire`** — Recupera il questionario adattato al settore dell'azienda
- **`PUT /assessment/{id}/context`** — Salva le risposte del questionario

### Funzionalità AI

- Se `ENABLE_AI_QUESTIONS = True` in `config.py` e `OPENAI_API_KEY` è configurata, genera automaticamente domande aggiuntive specifiche per il settore usando OpenAI GPT
- Le domande AI vengono categorizzate per topic ESRS

### Frontend (`frontend/src/app/assessment/page.tsx`)

- Questionario interattivo con **3 fasi** espandibili
- **Opzioni cliccabili** con highlight della selezione
- **Badge ESRS** per ogni domanda che mostra i topic correlati
- **Sezione AI** dedicata con domande generate dall'AI (in viola)
- Pulsante "Salva Questionario" per inviare le risposte al backend

## Step 9 - IRO Generator

### File creato: `ai-engine/materiality_engine/iro_generator.py`

Generatore di **Impatti, Rischi e Opportunità (IRO)** basato su:
1. Database IRO predefinito per settore NACE
2. IRO generici sempre applicabili
3. AI/LLM per IRO custom (opzionale)
4. Scoring iniziale automatico basato su benchmark di settore

### Database IRO per Settore

| Settore NACE | IRO Predefiniti | Temi Principali |
|-------------|-----------------|-----------------|
| **C** - Manifatturiero | 11 IRO | E1 (emissioni GHG, carbon pricing, efficienza), E2 (inquinamento, contaminazione), E3 (acqua), E5 (rifiuti, economia circolare), S1 (sicurezza, talenti), G1 (conformità) |
| **M** - Servizi Professionali | 6 IRO | E1 (ufficio, viaggi), S1 (wellbeing), S2 (fornitori), S4 (privacy), G1 (GDPR, cybersecurity) |
| **H** - Trasporti e Logistica | 3 IRO | E1 (flotta), flotta elettrica (opportunità), S1 (autisti) |
| **A** - Agricoltura | 3 IRO | E1 (emissioni agricole), E4 (biodiversità), E3 (acqua) |
| **F** - Costruzioni | 4 IRO | E1 (cantieri), E5 (rifiuti C&D, green building), S1 (sicurezza cantieri) |
| **G** - Commercio | 3 IRO | E1 (logistica), E5 (imballaggi), S2 (supply chain) |

**IRO Generici** (4, sempre applicabili): Scope 3, comunità locali, conformità ESG, consumo idrico operativo.

### Scoring Iniziale Automatico

Ogni IRO riceve uno scoring automatico basato su **benchmark di settore**:

```python
# Esempio benchmark per Manifatturiero (C)
{
    "carbon_intensity": "high",
    "water_intensity": "high",
    "waste_intensity": "high",
    "social_risk": "medium",
    "governance_risk": "medium",
    "typical_impact_range": (3.0, 4.5),     # 1-5
    "typical_financial_range": (2.5, 4.0),  # 1-5
}
```

- **Impact Scale**: 1-5 (dimensione impatto)
- **Financial Magnitude**: 1-5 (rilevanza finanziaria)
- **Impact Score**: media ponderata di scale + fattori di probabilità/gestione
- **Financial Score**: magnitudine finanziaria + probabilità
- **is_material**: True se impact_score o financial_score >= 3.0

### AI Generation

Due modalità:

1. **LLM (OpenAI)**: Chiamata a `gpt-4o-mini` con prompt context-aware che genera 2-4 IRO custom basati su settore, value chain, attività, geografia, stakeholder
2. **Rule-based fallback**: Se OpenAI non disponibile, genera IRO basati su regole contestuali:
   - Supply chain extra-EU → rischio ESRS S2
   - Operatività multi-paese (>3 paesi) → compliance multi-giurisdizione G1
   - Stakeholder multipli (>3 gruppi) → coinvolgimento stakeholder S3

### Endpoint API

- **`GET /assessment/{id}/iros`** — Recupera IRO generati (read-only, senza AI)
- **`POST /assessment/{id}/iros/generate`** — Genera nuovi IRO con opzione `use_ai` e `context_override`
- **`POST /assessment/{id}/scores/generate`** — Crea score entries nel database

### CLI Commands (in `ai-engine/cli.py`)

```bash
# Mostra questionario per settore
python cli.py questionnaire <company_id> <sector_code>

# Genera IRO standard
python cli.py generate-iros <company_id>

# Genera IRO con AI (richiede OPENAI_API_KEY)
python cli.py generate-iros <company_id> --use-ai
```

### Frontend (`frontend/src/app/assessment/page.tsx`)

- **Wizard** con 6 step progressivi (Contesto → IRO → Scoring → Gap Analysis → Matrice → Report)
- **Tab IRO**: lista completa con card color-coded (materiali in rosso, AI in viola)
- **Badge** per: tipo (impact/risk/opportunity), topic ESRS, materialità, AI-generated
- **Benchmark Card**: intensità carbonio/acqua/rifiuti/rischio sociale/governance
- **Metric Cards**: total IRO, materiali, benchmark-sourced, AI-generated
- **AI Dialog**: scelta tra "Generazione Standard" e "Generazione AI" con spiegazioni

### Altri file modificati

- **`frontend/src/types/index.ts`**: Nuove interfacce TypeScript (`IRO`, `IroSummary`, `SectorBenchmark`, `QuestionnaireQuestion`, `QuestionnairePhase`, `CompanyContext`, ecc.)
- **`frontend/src/lib/api.ts`**: Nuovi metodi `generateIros()`, `saveQuestionnaireResponses()`
- **`backend/app/api/assessment.py`**: Nuovi schemi `IroGenerateRequest`/`IroGenerateResponse`, endpoint POST per generazione IRO, aggiornamento endpoint esistenti per usare la nuova firma `IROGenerator.generate_iros_for_company()`
- **`ai-engine/cli.py`**: Nuovi comandi `generate-iros` e `questionnaire`
