### Step 8: Valutazione di Contesto Aziendale

**File:** `backend/app/services/context_questionnaire.py`

**Classe:** `ContextQuestionnaireService`

Questionario dinamico AI-adattivo in 3 fasi:

1. **Fase 1 - Universale**: settore NACE, dimensioni, fatturato, dipendenti, paesi operativi, value chain (upstream/downstream), stakeholder
2. **Fase 2 - Settoriale**: domande specifiche per codice NACE:
   - `C` (Manifatturiero): sostanze pericolose, rifiuti industriali, efficienza energetica, acqua
   - `J` (IT/Servizi): data center, fornitori extra-EU, lavoro remoto, e-waste
   - `M` (Professionale): viaggi business, fornitori esteri, lavoro ibrido
   - `H` (Logistica): flotta veicoli, magazzini, carburanti alternativi
   - `F` (Costruzioni): materiali, cantieri, rifiuti demolizione
   - `A` (Agricoltura): allevamento, suolo, fertilizzanti, biodiversità
   - `G` (Commercio): imballaggi, logistica, prodotti rivenduti
3. **Fase 3 - Value Chain**: mappatura dettagliata stakeholder, relazioni commerciali, impatti geografici

**Output:** Popola tabella `company_context` con tutti i campi strutturati.

**Metodi principali:**
- `get_all_questions(sector_code, phase)` → lista domande per fase
- `save_context(company_id, context_data)` → salva contesto nel DB
- `get_context(company_id)` → recupera contesto esistente
- `get_ai_adaptive_questions(company_id)` → domande AI-adattive basate su risposte precedenti

### Step 9: Identificazione IRO (Impacts, Risks, Opportunities)

**File:** `ai-engine/materiality_engine/iro_generator.py`

**Classe:** `IROGenerator`

Database predefinito di **~120 IRO template** organizzati per:

| Tipo | Quantità | Topic ESRS |
|------|----------|------------|
| Impact | 21 | E1-E5 (Climate, Pollution, Water, Biodiversity, Circular) + S1-S4 (Workforce, Supply Chain, Communities, Consumers) + G1 (Governance) |
| Risk | 40+ | E1 (Carbon price, transition, physical), E2 (regulatory, litigation), S1 (turnover, health), G1 (compliance, corruption) |
| Opportunity | 20+ | E1 (efficiency, renewables, carbon credits), S1 (talent, engagement), G1 (ESG financing, transparency) |

**Metodo `generate_iros_for_company(company_id)`:**

1. Recupera contesto aziendale dal DB
2. Filtra IRO per settore NACE
3. Aggiunge IRO universali (climate change base, governance base)
4. Applica esclusioni per settori non applicabili (es. agricoltura senza investimenti finanziari)
5. Assegna scoring predefinito (scale, magnitude) basato su benchmark di settore
6. Classifica severità: high (score ≥4), medium (≥2.5), low (<2.5)

**Output:** Lista IRO con type, topic, name, description, default_scores, severity.

### Step 10: Scoring Engine — Doppia Materialità

**File:** `ai-engine/materiality_engine/scoring_engine.py`

**Classe:** `ScoringEngine`

Implementa il calcolo della **doppia materialità** secondo EFRAG IG 1:

**Formule:**

```
Impact Score = (Scale × 0.3) + (Scope × 0.3) + (Irremediability × 0.2) + (Likelihood × 0.2)
Financial Score = (Magnitude × 0.6) + (Likelihood × 0.4)
Double Materiality Score = max(Impact_Score, Financial_Score)
```

**Threshold:** Score ≥ 3.0/5.0 → `is_material = True`

**Quadranti materialità:**

| Quadrante | Impact | Financial | Condizione |
|-----------|--------|-----------|------------|
| Double Material | ≥ 3.0 | ≥ 3.0 | Entrambi materiali |
| Impact Material | ≥ 3.0 | < 3.0 | Solo impatto |
| Financial Material | < 3.0 | ≥ 3.0 | Solo finanziario |
| Non Material | < 3.0 | < 3.0 | Nessuno |

**Metodi:**
- `score_single_datapoint(assessment_id, datapoint_id, scores)` — calcola e salva score per un datapoint
- `calculate_assessment_scores(assessment_id)` — calcola tutti gli score di un assessment
- `get_materiality_matrix(assessment_id)` — dati per scatter plot (array di {topic, impact_score, financial_score, is_material, label})
- `get_material_topics(assessment_id)` — lista topic ESRS materiali

**Pesi configurabili** tramite parametro `weights` nel costruttore.

### Step 11: Report di Doppia Materialità

**File:** `ai-engine/materiality_engine/materiality_report.py`

**Classe:** `MaterialityReportGenerator`

Genera report strutturato conforme a ESRS 2:

**Sezioni del report:**

1. **Executive Summary** — Riepilogo delle valutazioni materiali
2. **ESRS 2 IRO-1** — Description of the process:
   - Metodologia utilizzata (EFRAG IG 1)
   - Contesto aziendale e value chain
   - Stakeholder coinvolti
   - Topic ESRS materiali con conteggio
3. **ESRS 2 IRO-2** — Disclosure Requirements covered:
   - Tabella datapoint materiali per standard ESRS
   - Impact score e financial score per topic
   - Categorizzazione quadranti

**Metodi:**
- `generate_iro1_section(assessment_id)` — sezione IRO-1
- `generate_iro2_section(assessment_id)` — sezione IRO-2
- `generate_full_report(assessment_id)` — report completo
- `generate_narrative(topic, scores, company_context)` — genera descrizione testuale conforme ESRS via template

### Step 12: GHG Protocol Scope 1 Calculator

**File:** `ai-engine/carbon_calculator/scope1.py`

**Classe:** `Scope1Calculator`

Calcolo emissioni dirette (fonti possedute/controllate):

**Categorie implementate:**

| Categoria | Input | Fonte EF |
|-----------|-------|----------|
| 1. Stazionaria | Gas naturale (kWh), Gasolio (litri), LPG (kg), Biomassa (kg) | DEFRA 2025, IPCC AR6 |
| 2. Mobile | Diesel (km), Benzina (km), Elettrico (km) | DEFRA 2025 |
| 3. Fugitive | R410A (kg), R134a (kg), R32 (kg), R290 (kg) | IPCC AR6 GWP100 |

**Fattori di emissione principali:**
- Gas naturale: 0.184 kgCO2e/kWh
- Diesel riscaldamento: 2.540 kgCO2e/litro

- Veicolo benzina: 0.154 kgCO2e/km
- R410A: 2,088 kgCO2e/kg (GWP)
- R134a: 1,430 kgCO2e/kg (GWP)

**Metodo:** `calculate(activity_data)` → { total_tco2e, categories[], scope: "1" }

**Output:** tCO2e totali con breakdown per categoria e dettaglio per sottocategoria.

### Step 16: AI Validation Engine

**File:** `ai-engine/carbon_calculator/validation_engine.py`

**Classe:** `ValidationEngine`

**Controlli automatici:**

| Check | Descrizione | Soglia |
|-------|-------------|--------|
| Range check | Per-dipendente vs atteso PMI | 10-20,000 kgCO2e (S1), 50-15,000 (S2) |
| Sector benchmark | Confronto con mediana di settore | >3× benchmark = alert |
| Year-over-year | Variazione annuale | >50% = alert |
| Missing data | Dati mancanti per settore | Per NACE H senza fleet = alert |
| Unit consistency | Possibili errori unità | kg vs t, kWh vs MWh |

**Settori benchmark:**
- `C` Manifatturiero: S1 3,200 ±2,100 / S2 2,800 ±1,500 / dip. 100
- `J` IT: S1 250 ±180 / S2 800 ±400 / dip. 50
- `M` Professionale: S1 180 ±120 / S2 600 ±350 / dip. 40
- `H` Logistica: S1 12,000 ±5,000 / S2 3,500 ±2,000 / dip. 80
- `A` Agricoltura: S1 8,000 ±4,000 / S2 1,500 ±800 / dip. 30
- `F` Costruzioni: S1 1,500 ±1,000 / S2 1,200 ±700 / dip. 60
- `G` Commercio: S1 400 ±250 / S2 1,800 ±1,000 / dip. 35

**Output:**
```json
{
  "validation_score": 0-100,
  "high_severity": 0-∞,
  "medium_severity": 0-∞,
  "low_severity": 0-∞,
  "recommendation": "testo",
  "alerts": [
    {
      "type": "range_check|sector_benchmark|year_over_year|missing_data|unit_inconsistency",
      "severity": "high|medium|low",
      "scope": "1|2|3",
      "message": "descrizione",
      "suggestion": "suggerimento"
    }
  ]
}
```
