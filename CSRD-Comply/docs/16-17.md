# Step 16-17: AI Validation Engine & Template Engine per Report CSRD

## Step 16: AI Validation Engine per Dati Emissioni

### File: `ai-engine/carbon_calculator/validation_engine.py`

**Obiettivo**: Validare i dati di emissioni inseriti dall'utente con controlli automatici, rilevare anomalie e fornire suggerimenti correttivi.

### Benchmark di Settore (kgCO₂e/dipendente/anno)

| Settore | Scope 1 | Scope 2 | Scope 3 |
|---------|---------|---------|---------|
| **C** — Manifatturiero | 2.500 | 1.800 | 8.500 |
| **M** — Servizi Professionali | 400 | 600 | 2.500 |
| **H** — Logistica | 4.500 | 1.200 | 12.000 |
| **A** — Agricoltura | 5.500 | 800 | 6.000 |
| **F** — Costruzioni | 3.000 | 1.000 | 9.000 |
| **G** — Commercio | 600 | 1.500 | 4.000 |
| **J** — IT | 200 | 800 | 1.800 |
| **DEFAULT** | 1.000 | 1.000 | 5.000 |

### Controlli Implementati (ValidationEngine)

| Metodo | Tipo Controllo | Descrizione |
|--------|---------------|-------------|
| `check_range()` | **Range check** | Verifica se i dati per dipendente sono fuori range (min 10 - max 20.000 kgCO₂e per Scope 1) |
| `check_year_over_year()` | **YoY comparison** | Confronta anno corrente con anno precedente; alert se variazione > 50% |
| `check_sector_benchmark()` | **Benchmark settoriale** | Confronta con aziende simili per settore; alert se > 3x il benchmark |
| `check_missing_data()` | **Missing data detection** | Rileva dati mancanti per categoria (es. flotta per logistica, riscaldamento) |
| `check_unit_consistency()` | **Unit consistency** | Verifica coerenza unità di misura (t vs kg, kWh vs MWh) |
| `validate_all()` | **Validazione completa** | Esegue tutti i controlli e calcola punteggio 0-100 |

### Scoring di Validazione

- **Score 80-100**: Dati validati con successo ✅
- **Score 50-79**: Verifica i dati segnalati ⚠️
- **Score 0-49**: Dati non plausibili, correggi prima di procedere ❌

### Penalità per Severità
- **High**: -25 punti
- **Medium**: -10 punti
- **Low**: -3 punti

### Endpoint API Integrato

`POST /api/v1/emissions/validate` — Validazione completa con AI:
```json
{
  "scope1_tco2e": 120.5,
  "scope2_tco2e": 80.0,
  "scope3_tco2e": 450.0,
  "employee_count": 50,
  "sector_code": "J62",
  "has_stationary": true,
  "has_mobile": false,
  "has_fleet": false
}
```

### Integrazione con Backend

Il `ValidationEngine` è:
1. **Importato** in `backend/app/api/emissions.py` — endpoint `/validate` e validazione automatica in `/summary`
2. **Esportato** in `ai-engine/carbon_calculator/__init__.py`
3. **Usato** nel frontend nella pagina Emissioni per validazione real-time

## Step 17: Template Engine per Report CSRD

### File: `ai-engine/report_generator/template_engine.py`

**Obiettivo**: Creare il motore di template per la generazione di report CSRD conformi in formato XHTML + iXBRL.

### Architettura a Blocchi

```
ReportTemplate
├── CoverPage (copertina)
├── ReportSection (× N)
│   ├── section_id, standard_ref, title
│   ├── section_type: general | environmental | social | governance
│   ├── materiality_filter: always | if_material | conditional
│   └── DisclosureRequirement (× M)
│       ├── dr_id, title, paragraph_ref
│       ├── SubSections: governance, strategy, iro_management, metrics_targets
│       └── ContentBlock (× K)
│           ├── block_id, standard_ref, paragraph_ref
│           ├── content_html (HTML renderizzato)
│           ├── content_type: narrative | table | chart | list
│           ├── datapoint_refs: ["ESRS E1-6.54(a)", ...]
│           ├── XBRLTag (× P)
│           │   ├── concept: "esrs:E1-6_Scope1"
│           │   ├── unit_ref, context_ref
│           │   ├── scale, decimals
│           └── is_material: bool
```

### Classi Principali

| Classe | Ruolo |
|--------|-------|
| `ReportTemplate` | Template principale; gestisce struttura completa del report, rendering XHTML/iXBRL |
| `ReportSection` | Sezione del report (raggruppa DR sotto uno standard ESRS) |
| `DisclosureRequirement` | Disclosure Requirement ESRS (es. "E1-6") con blocchi e sottosezioni |
| `ContentBlock` | Blocco atomico di contenuto (narrativa, tabella, grafico, lista) |
| `XBRLTag` | Tag iXBRL per un datapoint (concept, unit, context, scale) |
| `CoverPage` | Dati per la copertina del report (azienda, anno, lingua) |

### Enums

| Enum | Valori |
|------|--------|
| `SectionType` | GENERAL, ENVIRONMENTAL, SOCIAL, GOVERNANCE, COMPLIANCE, ASSURANCE |
| `SubSectionType` | GOVERNANCE, STRATEGY, IRO_MANAGEMENT, METRICS_TARGETS |
| `MaterialityFilter` | ALWAYS (ESRS 2), IF_MATERIAL (E1-E5, S1-S4, G1), CONDITIONAL |

### Template HTML Base

Il report è renderizzato in XHTML valido con:
- **Namespace iXBRL**: `http://www.xbrl.org/2013/inlineXBRL`
- **Tassonomia ESRS**: `https://xbrl.efrag.org/esrs-set1-2023`
- **CSS integrato**: Cover page, sezioni, tabelle, compliance statement, footnotes

### Metodi Principali (ReportTemplate)

| Metodo | Descrizione |
|--------|-------------|
| `__init__(company_name, reporting_year, language)` | Inizializza template con metadati |
| `add_section(section)` | Aggiunge sezione (ordinata per `order`) |
| `add_block(section_id, dr_id, block)` | Aggiunge blocco a DR esistente |
| `set_materiality(material_standards)` | Imposta materialità sezioni (altre rimosse) |
| `remove_non_material_sections()` | Rimuove sezioni/blocchi non materiali |
| `render_content_html()` | Renderizza contenuto HTML (senza header/body) |
| `render_to_xhtml()` | Renderizza report XHTML completo |
| `render_to_ixbrl()` | Renderizza report iXBRL (XHTML + tag XBRL) |
| `to_dict()` / `to_json()` | Esporta struttura template in JSON |
| `create_default_template()` | **Factory method** — crea template con tutte le sezioni ESRS |

### Default Template (create_default_template)

Crea automaticamente la struttura completa del report CSRD:

| Ordine | Sezione | Standard | Tipo | Filtro |
|--------|---------|----------|------|--------|
| 1 | General Information | ESRS 2 | General | ALWAYS |
| 2 | Climate Change | ESRS E1 | Environmental | IF_MATERIAL |
| 3 | Pollution | ESRS E2 | Environmental | IF_MATERIAL |
| 4 | Water and Marine Resources | ESRS E3 | Environmental | IF_MATERIAL |
| 5 | Biodiversity and Ecosystems | ESRS E4 | Environmental | IF_MATERIAL |
| 6 | Resource Use and Circular Economy | ESRS E5 | Environmental | IF_MATERIAL |
| 7 | Own Workforce | ESRS S1 | Social | IF_MATERIAL |
| 8 | Workers in the Value Chain | ESRS S2 | Social | IF_MATERIAL |
| 9 | Affected Communities | ESRS S3 | Social | IF_MATERIAL |
| 10 | Consumers and End-users | ESRS S4 | Social | IF_MATERIAL |
| 11 | Business Conduct | ESRS G1 | Governance | IF_MATERIAL |

### Disclosure Requirement Inclusi

- **ESRS 2**: BP-1, BP-2, GOV-1, SBM-1, IRO-1, IRO-2 (con blocchi narrativi predefiniti)
- **ESRS E1**: E1-1 to E1-9 (con tabella GHG E1-6 con datapoint_refs per Scope 1,2,3)
- **ESRS E2-E5**: Policies, Actions, Targets, Metrics, Financial effects
- **ESRS S1-S4**: Policies, Stakeholder engagement, Remediation, Actions, Targets, Metrics
- **ESRS G1**: G1-1 to G1-6 (con blocco narrativo per corporate culture)

### Helper Functions

| Funzione | Descrizione |
|----------|-------------|
| `create_table_block()` | Crea ContentBlock tabella HTML da headers + rows |
| `create_narrative_block()` | Crea ContentBlock narrativo con testo formattato |

### Esempio d'Uso

```python
from ai_engine.report_generator import ReportTemplate, ReportSection

# Crea template predefinito
template = ReportTemplate.create_default_template(
    company_name="ACME Srl",
    reporting_year=2026,
    language="it",
)

# Imposta materialità (solo E1 e S1 sono materiali)
template.set_materiality(["ESRS E1", "ESRS S1"])

# Rimuovi sezioni non materiali
template.remove_non_material_sections()

# Renderizza XHTML
xhtml = template.render_to_xhtml()
with open("report.html", "w") as f:
    f.write(xhtml)

# Esporta in JSON
import json
with open("report_template.json", "w") as f:
    json.dump(template.to_dict(), f, indent=2, ensure_ascii=False)
```

- **Step 19**: Table Generator — popola le tabelle con dati reali
