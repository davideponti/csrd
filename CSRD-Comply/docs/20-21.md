## Step 20 — iXBRL Tagging Engine

### Architettura

```
XHTML dal TemplateEngine
        │
        ▼
┌─────────────────────────────┐
│   ESRSXBRLTaxonomy          │ ← Carica tassonomia XBRL (.xsd o default)
└─────────────────────────────┘
        │
        ▼
┌─────────────────────────────┐
│   IXBRLTagger               │
│   ┌───────────────────────┐ │
│   │ 1. Inietta namespace  │ │
│   │ 2. Link alla tax.     │ │
│   │ 3. Header iXBRL       │ │
│   │    (context + unit)   │ │
│   │ 4. Tagging facts      │ │
│   └───────────────────────┘ │
└─────────────────────────────┘
        │
        ▼
Documento .xhtml con iXBRL
```

### Componenti Principali

#### 1. `ESRSXBRLTaxonomy`
Loader della tassonomia ESRS:
- **Produzione**: carica da file `.xsd` ufficiale EFRAG usando `lxml`
- **Sviluppo**: usa mapping predefinito in `ESRS_DATAPOINT_MAP`
- Fornisce metodi `get_concept()`, `map_datapoint()`, `get_all_concepts()`

#### 2. `XBRLFact`, `XBRLContext`, `XBRLUnit`
Data classes per rappresentare fatti XBRL:
- **XBRLFact**: un singolo dato con concept, value, unit, context, scale, decimals
- **XBRLContext**: periodo, entità, scenario per contestualizzare il fatto
- **XBRLUnit**: unità di misura (es. tCO2eq, MWh, employees)

#### 3. `IXBRLTagger`
Il motore di tagging principale:

**Metodi chiave**:
- `tag_report(xhtml_content, xbrl_facts)` → applica tagging a documento XHTML
- `tag_report_from_template(template, company_data)` → da ReportTemplate + dati
- `tag_template_blocks(template)` → tagging a livello di singoli blocchi
- `extract_facts_from_xhtml(ixbrl_content)` → estrae fatti per debug
- `create_facts_from_company_data(company_data)` → crea fatti da dati aziendali

**Processo di tagging**:
1. Inietta namespace iXBRL (`ix:`, `xbrli:`, `xlink:`, ecc.) nel tag `<html>`
2. Aggiunge `<link rel="schema.esrs">` nel `<head>`
3. Genera header iXBRL (`<ix:header>`) con context e unit
4. Per ogni fatto numerico: sostituisce il valore con `<ix:nonFraction ...>valore</ix:nonFraction>`
5. Per ogni fatto testuale: aggiunge `<ix:nonNumeric ...>` nel blocco

### Mapping Datapoint → XBRL Concept

```python
ESRS_DATAPOINT_MAP = {
    "ESRS E1-6.Scope1":    {"concept": "esrs:GHGScope1Emissions",      "type": "nonFraction", "unit": "tCO2eq"},

    "ESRS E1-6.Total":     {"concept": "esrs:GHGTotalEmissions",       "type": "nonFraction", "unit": "tCO2eq"},
    "ESRS E1-5.Fossil":    {"concept": "esrs:EnergyFossilConsumption",  "type": "nonFraction", "unit": "MWh"},
    "ESRS S1-6.TotalEmployees": {"concept": "esrs:TotalEmployees",    "type": "nonFraction", "unit": "employees"},
    "ESRS 2.GOV-1":        {"concept": "esrs:GovernanceBodyRole",      "type": "nonNumeric"},
    ...
}
```

### Context iXBRL

Tre contesti predefiniti:
- **c_current**: periodo 01-01/YYYY to 12-31/YYYY (duration, anno corrente)
- **c_previous**: periodo 01-01/YYYY-1 to 12-31/YYYY-1 (duration, anno precedente)
- **c_instant**: data 12-31/YYYY (instant, per stock measures come employee count)

### Unit iXBRL

Unità predefinite: `u_tCO2eq`, `u_MWh`, `u_employees`, `u_EUR`, `u_percentage`, `u_kg`, `u_m3`

## Step 21 — iXBRL Validation Engine

### Architettura

```
┌─────────────────────────────┐
│   Report iXBRL (.xhtml)     │
└──────────┬──────────────────┘
           │
           ▼
┌──────────────────────────────────────────────────┐
│  IXBRLValidator                                  │
│                                                  │
│  ┌─────────────────────────────────────┐        │
│  │ 1. validate_template()              │        │
│  │    Struttura, dati obbligatori      │        │
│  ├─────────────────────────────────────┤        │
│  │ 2. validate_facts()                 │        │
│  │    Calcoli, unità, periodi, sintassi│        │
│  ├─────────────────────────────────────┤        │
│  │ 3. validate_file()                  │        │
│  │    Se Arelle disponibile → full     │        │
│  │    Altrimenti → built-in            │        │
│  └─────────────────────────────────────┘        │
└──────────────────────────────────────────────────┘
           │
           ▼
┌─────────────────────────────┐
│  ValidationResult           │
│  - passed (bool)            │
│  - score (0.0-1.0)          │
│  - issues (list)            │
│  - summary (str)            │
└─────────────────────────────┘
```

### Validazioni Built-in

#### 1. Calculation Linkbases
Verifica che i totali corrispondano alla somma dei componenti:
- Total GHG = Scope 1 + Scope 2 (location) + Scope 3 (±1%)
- Total Energy = Fossil + Nuclear + Renewable (±1%)
- Total Employees = Female + Male (esatto)

#### 2. Unit Consistency
Verifica che ogni concetto usi l'unità di misura corretta:
- GHG → tCO2eq/tCO2e
- Energy → MWh/kWh/GJ
- Workforce → employees/people/headcount

#### 3. Period Consistency
Verifica che i contesti siano coerenti (non più di 3 contesti diversi).

#### 4. Context Validation
Verifica che ogni fatto abbia un context_ref valido.

#### 5. Concept Validation
- Verifica formato concetto (deve iniziare con `esrs:`)
- Rileva concetti duplicati

#### 6. Syntax Validation
- Verifica che i valori numerici siano validi
- Segnala valori negativi insoliti (es. GHG negative)

#### 7. Dimensional Correctness
- Verifica che se ci sono componenti, esista anche il totale
- Verifica che se c'è il totale, siano presenti breakdown (o segnala)

### Integrazione con Arelle

Se Arelle (`arelleCmdLine`) è installato:

1. Scrive il contenuto iXBRL in file temporaneo
2. Esegue: `arelleCmdLine --file report.xhtml --validate --output validation.json`
3. Legge e interpreta l'output JSON
4. Mappa errori Arelle → ValidationIssue
5. Classifica per categoria (schematron, calculation, unit, ecc.)
6. Suggerisce correzioni

**Fallback automatico**: se Arelle non è disponibile, usa solo validazioni built-in.

### Scoring

```
Score = 1.0 (base)
       - FATAL × 0.3
       - ERROR × 0.15
       - WARNING × 0.05
       - INFO × 0.01
Score minimo: 0.0
PASSED se: fatal_count == 0 AND error_count == 0
```

### Usage End-to-End

```python
from ai_engine.report_generator import (
    ReportTemplate,
    NarrativeGenerator,
    TableGenerator,
    IXBRLTagger,
    IXBRLValidator,
)

# 1. Template
template = ReportTemplate.create_default_template(
    company_name="ACME Srl",
    reporting_year=2026,
    language="it",
)
template.set_materiality(["ESRS E1", "ESRS S1"])
template.remove_non_material_sections()

# 2. Narrative
narratives = NarrativeGenerator(provider="openai").generate_batch(inputs)

# 3. Tables
tables = TableGenerator(language="it").render_all_tables(company_data)

# 4. iXBRL Tagging
tagger = IXBRLTagger()
ixbrl = tagger.tag_report_from_template(template, company_data)

# 5. Validation
validator = IXBRLValidator()
result = validator.validate_facts(
    tagger.extract_facts_from_xhtml(ixbrl)
)
print(result.summary())
# Output: Validation ✅ PASSED
# Score: 100.0%
# Issues: 0 (Fatal: 0, Error: 0, Warning: 0, Info: 0)
```
