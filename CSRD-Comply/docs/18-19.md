# Step 18-19: AI Narrative Generator & Table Generator

## Step 18: AI Narrative Generator

### File: `ai-engine/report_generator/narrative_generator.py`

**Obiettivo**: Generare il testo narrativo del report CSRD usando LLM (OpenAI / Anthropic). Per ogni Disclosure Requirement narrativo (es. "Describe the governance structure for managing climate-related impacts"), usa un LLM per generare testo professionale e conforme.

### Architettura

```
NarrativeGenerator
├── Input: NarrativeInput
│   ├── datapoint_ref (es. "ESRS E1-6.54(a)")
│   ├── dr_title, dr_description (testo legale ESRS)
│   ├── company_data (emissioni, punteggi, workforce)
│   ├── materiality_results (risultati doppia materialità)
│   ├── previous_report_text (report anno precedente, opzionale)
│   └── language (en, it, de, fr, es)
│
├── LLM Provider (OpenAI GPT-4o / Anthropic Claude 3.5)
│   ├── System Prompt (consulente senior ESRS)
│   ├── Few-shot examples (3 esempi reali)
│   └── User Prompt (contesto + dati + istruzioni)
│
├── Anti-Hallucination Layer
│   ├── validate_narrative()
│   │   ├── Check 1: Datapoint ref citato
│   │   ├── Check 2: Numeri corrispondono a dati reali
│   │   ├── Check 3: No linguaggio incerto per dati certi
│   │   └── Check 4: Normative valide
│   └── Rigenerazione automatica se validation fallisce
│
└── Output: NarrativeOutput
    ├── narrative_text (testo generato)
    ├── confidence (0.0-1.0)
    ├── validation_passed (bool)
    ├── validation_issues (lista issue)
    └── tokens_used
```

### Prompt Engineering

| Elemento | Dettaglio |
|----------|-----------|
| **System Prompt** | "Sei un consulente senior di sostenibilità con 15+ anni di esperienza in reportistica CSRD" |
| **Lingue** | EN, IT con prompt dedicati |
| **Few-shot** | 3 esempi: E1-6 (GHG), GOV-1 (Governance) |
| **Constraints** | Max 300 parole/paragrafo, cita fonti, solo dati forniti |
| **Temperatura** | 0.3 (bassa, più deterministico) |

### Anti-Hallucination Layer

| Controllo | Descrizione |
|-----------|-------------|
| `validate_narrative()` | Valida testo generato contro dati reali |
| Riferimenti datapoint | Verifica che `datapoint_ref` sia citato |
| Dati numerici | Cerca valori numerici nel testo |
| Linguaggio incerto | Rileva "maybe", "might", "could be" per dati certi |
| Rigenerazione | Fino a 2 tentativi con note correttive |

### Classi Principali

| Classe | Ruolo |
|--------|-------|
| `NarrativeGenerator` | Generatore principale con supporto OpenAI/Anthropic |
| `NarrativeInput` | Input strutturato (datapoint, dati, contesto) |
| `NarrativeOutput` | Output con testo, confidence, validazione |

### Helper Functions

| Funzione | Descrizione |
|----------|-------------|
| `create_narrative_input_from_block()` | Crea `NarrativeInput` da un `ContentBlock` del template |
| `update_template_with_narratives()` | Aggiorna `ReportTemplate` con testi generati |
| `generate_report_narratives_api()` | Helper per endpoint API: genera tutte le narrative |

### Esempio d'Uso

```python
from ai_engine.report_generator import NarrativeGenerator, NarrativeInput

generator = NarrativeGenerator(provider="openai")

n_input = NarrativeInput(
    datapoint_ref="ESRS E1-6.54(a)",
    dr_title="Gross Scopes 1, 2, 3 and Total GHG emissions",
    dr_description="The undertaking shall disclose its gross GHG emissions...",
    company_data={"scope1": 105, "scope2": 75, "scope3": 420},
    language="en",
)

output = generator.generate(n_input)
print(output.narrative_text)  # Testo generato e validato
print(f"Confidence: {output.confidence}")
print(f"Validated: {output.validation_passed}")
```

## Step 19: Table Generator

### File: `ai-engine/report_generator/table_generator.py`

**Obiettivo**: Generare tabelle ESRS-compliant e dati per grafici interattivi. Ogni Disclosure Requirement quantitativo richiede una tabella con formati specifici per ogni datapoint.

### Tipi Tabella Supportati

| Tipo | Descrizione | ESRS Ref |
|------|-------------|----------|
| `ghg` | GHG emissions (Scope 1, 2, 3) | E1-6 |
| `energy` | Energy consumption & mix | E1-5 |
| `water` | Water consumption | E3-4 |
| `waste` | Waste metrics | E5-5 |
| `workforce` | Workforce demographics | S1-6 |
| `comparative` | N vs N-1 comparison | Generico |
| `multi_year` | Multiple years trend | Generico |
| `breakdown` | By country/sector/subsidiary | Generico |
| `custom` | Custom table from arbitrary data | — |

### Architettura

```
TableGenerator
├── generate_ghg_table(emissions_data)
│   ├── Scope 1, 2, 3 con confronto N vs N-1
│   ├── Calcolo automatico variazioni %
│   ├── Scope 3 breakdown per categoria
│   └── ChartData opzionale (bar chart)
│
├── generate_energy_table(energy_data)
│   ├── Fonti: fossile, nucleare, rinnovabile
│   └── Breakdown per sotto-categoria
│
├── generate_workforce_table(workforce_data)
│   ├── Breakdown per genere
│   └── Per tipo contratto
│
├── generate_comparative_table()
│   └── Multi-year comparison
│
├── generate_breakdown_table()
│   └── Per paese/settore/subsidiary
│
├── render_table_html(table) → HTML
│   ├── CSS dedicato (stile ESRS)
│   ├── Attributi iXBRL opzionali
│   └── Chart data come JSON embeddato
│
└── render_all_tables(data) → Dict[id → HTML]
```

### Tabella GHG Example (ESRS E1-6)

|---------------|----------|--------|------------|
| Scope 1 (tCO2e) | 120.0 | 105.0 | -12.5% |
| Scope 2 location-based (tCO2e) | 80.0 | 75.0 | -6.3% |
| Scope 2 market-based (tCO2e) | 45.0 | 30.0 | -33.3% |
| Scope 3 total (tCO2e) | 450.0 | 420.0 | -6.7% |
| **Total GHG emissions (tCO2e)** | **650.0** | **600.0** | **-7.7%** |

### Data Classes

| Classe | Ruolo |
|--------|-------|
| `ESRSDataTable` | Tabella ESRS completa (type, columns, rows, chart) |
| `TableColumn` | Colonna con header, field, unit, format, alignment |
| `TableRow` | Riga con label, values dict, is_total, indent |
| `ChartData` | Dati per grafico (chart_type, labels, datasets) |

### HTML Rendering

- **CSS**: Stile professionale ESRS (intestazioni blu, righe alternate, totali grassetto)
- **iXBRL-ready**: Attributi `data-ixbrl-concept`, `data-ixbrl-unit`, etc.
- **Grafici**: Dati JSON embeddati per Chart.js / Recharts
- **Footnotes**: Note a piè di pagina con metodologia

### Helper Functions

| Funzione | Descrizione |
|----------|-------------|
| `generate_report_tables_api()` | Helper per endpoint API: genera tutte le tabelle |
| `update_template_with_tables()` | Aggiorna `ReportTemplate` con tabelle popolate |

### Integrazione End-to-End

```
Company Data → TableGenerator → ESRSDataTable → render_table_html()
                                        ↓
                              update_template_with_tables()
                                        ↓
                              ReportTemplate (sezioni popolate)
                                        ↓
                              render_to_xhtml() / render_to_ixbrl()
```
