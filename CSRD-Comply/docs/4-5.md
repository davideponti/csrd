Rimpiazzare il CSS grezzo con una libreria di componenti professionale basata su **shadcn/ui**, garantendo consistenza visiva, accessibilità e manutenibilità.

```
npm install clsx tailwind-merge class-variance-authority lucide-react
npm install @radix-ui/react-slot @radix-ui/react-tabs @radix-ui/react-select @radix-ui/react-dialog @radix-ui/react-progress
```

- `--background`, `--foreground`, `--card`, `--popover`
- `--primary`, `--secondary`, `--muted`, `--accent`, `--destructive`

## Step 5 — CLI Runner e Gap Analysis Backend

### Obiettivo
Creare un'interfaccia CLI per l'AI Engine e integrare la Gap Analysis automatica nel backend API.

### File Creati

#### `ai-engine/cli.py`
CLI runner con comandi:

```bash
python cli.py seed-sustainability    # Seed sustainability_matters table
python cli.py ingest-taxonomy        # Ingest ESRS taxonomy da Excel
python cli.py seed-all               # Seed + Ingest
python cli.py gap-analysis <id>      # Gap analysis per company
```

**Generatore dati sintetici** (`_generate_synthetic_data`): produce 50 datapoint ESRS quando il file Excel non è presente:
- **E - Environment** (E1 Climate, E2 Pollution, E3 Water, E4 Biodiversity, E5 Circular Economy): 31 datapoint
- **S - Social** (S1 Own Workforce, S2 Value Chain Workers, S3 Communities, S4 Consumers): 14 datapoint
- **G - Governance** (G1 Business Conduct): 5 datapoint

#### `ai-engine/__init__.py`
Package marker per l'AI Engine.

### File Modificati

#### `backend/app/api/assessment.py`
Aggiunto endpoint per gap analysis:

```
GET /api/v1/assessment/{assessment_id}/gap-analysis
```

- Recupera company dell'utente corrente
- Inizializza `GapAnalyzer(db)` 
- Restituisce `get_summary(company_id)` con:
  - `total_required`, `complete`, `partial`, `missing`
  - `completion_percentage`
  - `gaps_by_standard` (raggruppamento per standard ESRS)
  - `priority_actions` (azioni prioritarie ordinate per criticalità)

#### `backend/app/api/router.py`
Confermata inclusione router assessment con prefisso corretto.

#### `frontend/src/lib/api.ts`
Aggiunto metodo API client:
```typescript
assessments.getGapAnalysis(id: string) => GET /assessment/{id}/gap-analysis
```

### Struttura Dati Gap Analysis

```json
{
  "total_required": 50,
  "complete": 12,
  "partial": 18,
  "missing": 20,
  "completion_percentage": 24.0,
  "gaps_by_standard": {
    "ESRS E1": { "required": 14, "complete": 3, "partial": 5, "missing": 6 },
    ...
  },
  "priority_actions": [
    {
      "datapoint": "Gross Scope 1 GHG emissions (tCO2e)",
      "standard_ref": "ESRS E1-4",
      "priority": "critical",
      "effort": "medium",
      "suggestion": "Inserire dati ESRS E1-4: Gross Scope 1 GHG emissions"
    }
  ]
}
```

### Integrazione Frontend
La Gap Analysis è integrata nella pagina `assessment/page.tsx`:
- Tab "Gap Analysis" nel wizard assessment
- Bottoni: "Avvia Gap Analysis"
- Visualizzazione metriche (total_required, complete, partial, missing)
- Progress bar completion percentage
- Lista priority actions con badge colore (critical=red, high=yellow, medium=gray)
