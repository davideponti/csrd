# Step 24-25: AI Regulatory Summarizer + AI Regulatory Advisor

## Panoramica

Questi due step completano il **Regulatory Intelligence Module** (Fase 5 del piano), 
aggiungendo capacità di analisi e consulenza normativa basate su AI:

- **Step 24**: `UpdateAnalyzer` — Riassume cambiamenti normativi CSRD/ESRS 
  in linguaggio comprensibile per PMI, classificandone l'impatto.
- **Step 25**: `RegulatoryAdvisor` — Genera task list personalizzate, allerte 
  scadenze e suggerimenti per ogni azienda basandosi sul suo profilo.

## Step 24: AI Summarizer per Update Normativi

### `ai-engine/regulatory_intelligence/update_analyzer.py`

Il **UpdateAnalyzer** analizza documenti normativi EU e produce riassunti 
strutturati per diversi livelli di audience aziendale.

#### Data Classes

| Classe | Descrizione |
|--------|-------------|
| `ImpactClassification` | CRITICAL (obbligatorio), MODERATE (linee guida), INFO (chiarimenti) |
| `AffectedEntityType` | ALL_COMPANIES, SECTOR_SPECIFIC, SIZE_SPECIFIC, COUNTRY_SPECIFIC, WAVE_SPECIFIC |
| `RegulatoryChange` | Singola modifica normativa con old/new requirement |
| `AnalyzedUpdate` | Risultato completo dell'analisi |
| `CompanyNotification` | Notifica preparata per una specifica azienda |

#### Classi principali

**ContentDownloader**: Scarica il testo completo di documenti normativi.
- Download di HTML e PDF
- Estrazione testo via BeautifulSoup (HTML) o PyPDF2 (PDF)
- Timeout 60s, User-Agent personalizzato

**UpdateAnalyzer**: Il cuore dell'analisi.
- Usa LLM (OpenAI GPT-4o o Anthropic Claude) per generare:
  - **Summary CEO**: 2-3 frasi in linguaggio semplice
  - **Detail Compliance**: parametri tecnici per compliance officer
  - **Action Items**: cosa deve fare l'azienda
- Fallback rule-based quando LLM non disponibile
- Rilevamento automatico del regolamento (CSRD, ESRS, EU Taxonomy, SFDR, etc.)
- Identificazione standard ESRS menzionati

#### Funzioni Utility

```python
analyze_update(title, source, url, content=None, api_key=None, provider="openai")
analyze_update_sync(...)
batch_analyze_updates(documents, api_key=None, provider="openai")
```

### Flusso di analisi

1. Documento normativo → ContentDownloader scarica testo completo
2. Testo + prompt → LLM → Analisi strutturata JSON
3. Parsing JSON → AnalyzedUpdate con campi tipizzati
4. Enrichment: estrazione riferimenti normativi, date, standard
5. Se LLM fallisce → Fallback rule-based

## Step 25: AI Regulatory Advisor

### `ai-engine/regulatory_intelligence/advisor.py`

Il **RegulatoryAdvisor** genera un report personalizzato per ogni azienda,
combinando aggiornamenti normativi, profilo aziendale e stato corrente.

#### Data Classes

| Classe | Descrizione |
|--------|-------------|
| `TaskPriority` | CRITICAL, HIGH, MEDIUM, LOW |
| `TaskCategory` | COMPLIANCE, DATA_COLLECTION, EMISSIONS, MATERIALITY, REPORTING, REGULATORY, TRAINING |
| `AdvisorTask` | Task consigliato con scadenza, suggerimento AI, effort estimate |
| `DeadlineAlert` | Allerta scadenza con severity (critical/warning/info) |
| `AdvisorSuggestion` | Suggerimento contestuale con action link |
| `AdvisorReport` | Report completo per un'azienda |

#### Classi principali

**RegulatoryAdvisor**: Genera report completi.

Metodo principale:
```python
advisor = RegulatoryAdvisor()
report = advisor.generate_report(
    company_id="...",
    company_profile={"sector": "...", ...},
    regulatory_updates=[...],
    gap_analysis={...},
    emissions_summary={...},
    assessment_status={...},
)
```

### Output del Report

1. **Task List** (ordinata per priorità):
   - Task base: questionario, IRO, emissioni, gap analysis, report
   - Task da aggiornamenti CRITICAL
   - Ogni task ha: scadenza, suggerimento AI, effort estimate

2. **Deadline Alerts**:
   - Scadenze CSRD per wave (filing, assessment, data collection)
   - Allerte da task con scadenze <= 90 giorni
   - Severity: critical <= 30gg, warning <= 60gg, info > 60gg

3. **Suggestions** (contestuali e personalizzati):
   - Gap significativi in specifici standard ESRS
   - Emissioni mancanti
   - Assessment non completato
   - Scadenze imminenti

4. **Compliance Score** (0-100):
   - Gap analysis completion: 40%
   - Emissioni inserite (Scope 1,2,3): 30%
   - Assessment materialità completato: 30%
